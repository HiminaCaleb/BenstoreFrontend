# BenstoreFrontend
Frontend reference prototypes for delivery apps (starting with Mr D)

## Prototypes

### Mr D (`mr_d/`)
Interactive frontend reference prototype modeled after South Africa's popular Mr D on-demand delivery app (Food, Pick n Pay Groceries, Liquor, TakealotNOW).

- **`index.html`**: Semantic structure including store directory, item customizer modal, slide-out basket drawer, checkout flow, and live delivery tracking simulator.
- **`styles.css`**: Complete Mr D brand design system (signature yellow & jet charcoal), responsive desktop/mobile layouts, micro-interactions, and elevation tokens.
- **`app.js`**: Pure vanilla ES6+ logic with state management, store search and filtering, item customization, cart billing calculations in ZAR, voucher validation (`MRD50`, `FREEDEL`), location switching, and live driver tracking simulation.
